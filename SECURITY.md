# Security reporting

Send security reports privately to github@blahh.us after the owner confirms that
contact. Do not post player saves, credentials, tokens or private support reports
in public issues. This project is not yet a published security contact service.

The app rejects executable saved Lua, verifies signed release/advice metadata,
bounds downloads and archive paths, and preserves personal game data. Report a
specific failing case; the existence of these checks is not a security guarantee.

Public keys and service URLs are intentionally public. Signing private keys,
registration credentials and personal data must never enter this repository.
